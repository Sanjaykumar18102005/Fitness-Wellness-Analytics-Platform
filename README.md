# Fitness Wellness Analytics Platform

A Node.js backend for managing fitness and wellness data, built with Express. This repository includes structure for controllers, models, routes, services, middleware, and configuration, along with Docker support and testing scaffolds.

## Quick Start
```bash
npm install
npm run dev
```

## Docker
```bash
docker compose up --build
```

## Testing
- Unit tests go under `tests/unit`
- Integration tests go under `tests/integration`
